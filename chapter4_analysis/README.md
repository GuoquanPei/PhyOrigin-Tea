# 第4章 地域差异与环境关联

本章对应论文PDF第14页。当前提供实验方案，尚未运行统计分析。输入来自第3章预测表型与有效尺度标定，不能用虚构环境值填补。

## 推荐实验

| 实验 | 方法与应报告结果 |
| --- | --- |
| 地域描述与差异 | 按器官/叶位和真实独立采样层级统计样本数、均值/标准差或中位数/IQR；报告效应量、区间及多重比较校正 |
| 多维地域结构 | 尺度可比的表型标准化后PCA及层次聚类，给出载荷、解释率、稳定性；分群仅作探索证据 |
| 主脉差异 | 弧长、弧弦比与叶位、叶片尺寸的关系；区分人工参照与自动测量 |
| 环境关联 | 预设少量表型—环境组合的Spearman/Pearson及区间；采样前生长窗口；适当控制共线性及层级 |
| 联合分析与特征筛选 | 有效独立n允许时用低维模型；按测量稳定性、效应量、冗余和环境关联筛选，保留探索性质 |

## 输入数据约定

图像与特征以`sample_id`关联`chapter3_segmentation/data/manifest.csv`；另需明确真实`specimen_id`、采样单元、采样日期和设备。环境表推荐字段：`site, sampling_unit_id, observation_date, window_start, window_end, altitude_m, latitude, longitude`及有单位的气象变量。每项需注明采集方法、缺失与汇总窗口。没有可靠join键的图像不能强行匹配环境。

若一个茶园共享一条环境记录，有效环境样本数是独立茶园数，不能因有999图就写n=999。原开题列11茶园、46单元、920图，与当前999图需核对版本。11个茶园不支持同时估计大量环境变量和深度特征的高维联合模型。

相机与扫描仪产地不重叠，地域差异可能混入成像差异。无可靠标尺的像素面积不直接跨设备比较。PCA、标准化、特征筛选若用于第5章预测，应在其训练折内重新拟合，禁止利用测试标签筛选特征。观测关联不等于环境因果效应。
