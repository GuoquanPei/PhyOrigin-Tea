正式流水线使用第3章预测掩膜及特征；人工真值掩膜只作单列的性能上限参照。器官缺失必须显式记录。输入不默认包含地点编码、海拔、经纬度等可直接暴露产地的变量。

评价包括总体准确率、宏Precision/Recall/F1、Kappa、逐类召回和混淆矩阵，以及独立采样组层面的区间。对比采用统一划分和调参预算。增加去芽、去叶1、去叶2、去茎、去除/打乱结构、去主脉表型和简单拼接对照；真实实现后才报告消融结果。

复用`chapter3_segmentation/data/manifest.csv`：第5章测试对象的人工掩膜不得用于第3章分割训练；特征选择、标准化、填补与融合调参均在训练/验证集内完成。交叉验证时，应在外层训练组内重新适配分割器及特征选择。种子重复反映优化波动，不能当作独立生物重复。

鲁棒性可先测试亮度、颜色、模糊等预设扰动。当前相机7产地与扫描仪4产地不重叠，不能据此完成同类别真实跨设备迁移；需要补采同产地的两设备独立样本。将整类产地留出已改变闭集分类任务，不与普通闭集测试混报。
